# Mindful Paws — Pet Grooming Landing Page

A calm, responsive landing page for **Mindful Paws**, a boutique pet grooming salon. The site is built as a single self-contained HTML file with inline CSS and JavaScript—no frameworks, dependencies, or build step required.

## Features

- Responsive hero, salon promises, services, pet gallery, and booking sections.
- Interactive three-step estimate quiz for pet type, size, and service.
- Accessible controls, mobile navigation, visible focus states, and reduced-motion support.
- Booking request form with required-field validation and preferred date selection.
- Self-contained pet illustrations; no remote image requests.

## Services

| Service | Starting price |
| --- | ---: |
| Bath & Brush | $45 |
| Full Groom | $75 |
| Spa Day | $120 |
| Puppy's First Groom | $55 |

The quiz estimates Bath & Brush, Full Groom, and Spa Day. Its estimate adds $15 for medium pets or $30 for large pets, plus $10 for cats or $15 for other pet types. Final pricing may vary based on coat and care needs.

## Run locally

Open [`mindful_paws.html`](./mindful_paws.html) in a modern web browser. There is no install or build step.

The booking form is a front-end demonstration: submitting it shows a local confirmation message, but does not send or store a booking. Contact the salon directly to confirm an appointment.
